# Godot llm-lint v0.6.0

- Upgrades the pinned gdstyle tool from 0.3.1 to 0.8.0.
- Enables `gdstyle/format/extra-spacing` as an error. It catches excess spaces
  and tabs between tokens, including padding inside calls and brackets.
- Refreshes rule examples for the new pin. Existing projects may see new
  diagnostics from the formatter and from rules whose behavior changed upstream.

## Upgrade from v0.5.0

1. Install v0.6.0 using the [installation guide](../../README.md#install).
2. Run `godot-llm-lint init` from the project root. It verifies 0.8.0 before
   migrating either 0.3.1 configuration format and regenerating `gdstyle.toml`.
   For offline setup, pass the official archive with `--gdstyle-archive`.
3. Review and commit the two configuration files. Run `godot-llm-lint check --json`
   to review findings under the new pin. If you record lint history, record a
   new baseline for the upgraded version.

See the [gdstyle 0.8.0 release](https://github.com/atelico/gdstyle/releases/tag/v0.8.0)
and the [native tool setup guide](../usage.md#native-tool-setup-and-trust).
