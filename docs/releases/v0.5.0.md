# Godot llm-lint v0.5.0

- Inspect incoming and outgoing references by path or UID with `references`.
- Explain stale document reviews against a Git revision with `--doc-baseline`.
- Use `--timings` to inspect check phases and `--duplicate-warnings` to select
  the terminal warnings you want to see.
- Review potentially unused assets and declarations with `unused`.
- The official gdstyle binary now runs from a caller-controlled, per-user
  cache. Release archives have SHA-256 checksums and GitHub build provenance.

## Upgrade from 0.4.0

1. Install the new version using the [installation guide](../../README.md#install).
2. Run `godot-llm-lint init` in the project root to provision the per-user
   cache and migrate the old checkout-local native configuration. For offline
   setup, pass the official archive or executable explicitly.
3. Review and commit the config changes. Run `godot-llm-lint sync --check`
   and `godot-llm-lint check --json`.
4. If you previously recorded lint history, record a new baseline for 0.5.0.
   Baselines are matched to the linter and policy versions.

The [usage guide](../usage.md#native-tool-setup-and-trust) covers trusted custom
gdstyle builds and the new cache paths.
