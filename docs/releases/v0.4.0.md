# Godot llm-lint v0.4.0

- Maintained Markdown checks now cover document metadata, role blueprints,
  declared-source freshness, and size. Use `docs review` to refresh review
  metadata after reading the declared sources and updating the prose.
- GDScript access checks now cover underscore-prefixed private members and
  access to them from other scripts. Use a public method for cross-script calls.
- [Opt-in lint history](../usage.md#lint-history) records full checks locally
  and compares rule findings by model and selected baseline in terminal or HTML reports.
- The README shows [before-and-after examples](../../README.md#before-and-after-examples).
  The [rule reference](../rules.md) links to executable fixtures, and the
  [usage guide](../usage.md) covers configuration and migration.

## Upgrade from 0.3.0

1. Install the tagged source or the archive for your host using the
   [installation instructions](../../README.md#install).
2. In the project root, run `godot-llm-lint init` if the pinned native tool
   needs provisioning. Run `godot-llm-lint sync` with your existing project
   configuration to refresh generated `gdstyle.toml`.
3. Run `godot-llm-lint architecture --json` to review new findings. Follow
   the [Markdown workflow](../usage.md#maintained-markdown) for living documents
   and update cross-script access to use public methods. Finish with
   `godot-llm-lint check`.
